# Iris Flower Classification 🌸

## Project Overview
This project uses Machine Learning to classify Iris flowers into three species:
- Setosa
- Versicolor
- Virginica

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Project Workflow
1. Importing libraries
2. Loading the Iris dataset
3. Data exploration and analysis
4. Data visualization
5. Splitting data into training and testing sets
6. Training a K-Nearest Neighbors (KNN) model
7. Evaluating model performance
8. Applying Feature Scaling using StandardScaler
9. Comparing model performance
10. Predicting a new flower species

## Machine Learning Algorithm
K-Nearest Neighbors (KNN) Classification.

## Model Evaluation
The models were evaluated using:
- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix

## How to Run
1. Download the notebook.
2. Open [Google Colab](https://colab.research.google.com/).
3. Upload the `.ipynb` file.
4. Run the notebook cells in order.
